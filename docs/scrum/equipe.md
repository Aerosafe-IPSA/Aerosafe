## Rôles Scrum

| Rôle | Membre | Responsabilités |
|---|---|---|
| Product Owner | **Lucas** | Porte la vision produit, tient et priorise le backlog (issues GitHub), rédige les critères d'acceptation, accepte ou refuse les stories en revue de sprint. |
| Scrum Master | **Tov** | Garant de la méthode : anime planning, daily et rétrospective, lève les obstacles, veille au respect du workflow Git (PR, relectures), administre le dépôt. |
| Équipe de développement | **Tov, Lucas, Teddy, Ryan** | Estime les stories, se répartit les tâches, développe, teste et relit le code des autres. |
